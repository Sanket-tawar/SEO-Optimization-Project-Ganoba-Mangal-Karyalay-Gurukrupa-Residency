# SEO-Optimization-Project-Ganoba-Mangal-Karyalay-Gurukrupa-Residency
This project involves end-to-end local SEO planning and optimization for two businesses in Pusad and Yavatmal, Maharashtra:  Ganoba Mangal Karyalay – A wedding hall / event venue 
Gurukrupa Residency – A hotel / guest accommodation

The goal was to improve local search visibility on Google for relevant queries like *"wedding hall in Pusad"*, *"banquet hall Yavatmal"*, and *"hotel near Pusad"*.

## SEO Strategy

### 1. On-Page SEO
- Created SEO-optimized title tags and meta descriptions for all key pages
- Defined heading structure (H1 → H2 → H3) following SEO best practices
- Planned image ALT text strategy with location + keyword-rich descriptions
- Mapped primary and secondary keywords to specific pages

### 2. Website Structure & URL Hierarchy
Planned a flat, crawlable URL structure:
```
/ (Home)
/wedding-hall-pusad
/hotel-pusad
/gallery
/contact
/blog
/blog/[post-slug]
```

### 3. Local SEO
- Optimized for location-based keywords (city + service)
- Planned Google Business Profile (GBP) optimization
- NAP consistency strategy (Name, Address, Phone) across the site
- Schema markup recommendations (LocalBusiness, Event)

### 4. Technical SEO (React + Vite)
- Recommended React Helmet / react-helmet-async for dynamic meta tags
- Advised on sitemap generation (`vite-plugin-sitemap`)
- Suggested robots.txt configuration
- Core Web Vitals improvement recommendations (image optimization, lazy loading)
- Recommended canonical tag usage to avoid duplicate content

### 5. Content Strategy
- Developed blog content ideas targeting informational keywords
- Planned internal linking between blog posts and service pages
- Suggested FAQ sections to capture voice search and featured snippet opportunities
